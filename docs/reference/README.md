# Reference

Dry, complete, accurate. Every symbol here is exported from `pydantic_prism`
and exercised by the test suite.

- **[API reference](api.md)** — every public symbol: markers, scopes, the
  `ScopedModel` / `Projection` methods, the relationship graph, governance,
  and diagram export.
- **[CLI reference](cli.md)** — the `prism` console script: `gen`, `check`,
  `diagram`, `flow`, and the `[tool.pydantic-prism]` config.
- **[Errors](errors.md)** — the exception hierarchy and the situation → error
  → when table.

For tutorials and recipes that *use* these symbols, see the
[how-to guides](../how-to/README.md). For the reasoning behind the design, see
[explanation](../explanation/README.md).
